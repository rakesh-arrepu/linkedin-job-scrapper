# Examples

This directory contains example scripts demonstrating how to use the LinkedIn Job Scraper.

## Files

- `example_usage.py` - Demonstrates programmatic usage of the scraper

## Running Examples

### Using the Library Programmatically

```bash
python examples/example_usage.py
```

This will demonstrate:
1. Basic job search
2. Advanced search with filters
3. Exporting to multiple formats
4. Job enrichment
5. Custom filters

### Command-Line Examples

See the main README.md for comprehensive CLI examples.

## Example Outputs

All examples output files to `./output/examples/` directory:
- `jobs_report.pdf` - Detailed PDF report
- `jobs_data.csv` - CSV export
- `jobs_data.json` - JSON export
